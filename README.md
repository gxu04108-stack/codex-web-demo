# 我的第一个 Codex Web 项目

一个完全通过 Codex Web 创建的现代中文静态首页。项目仅使用 HTML、CSS 和原生 JavaScript，无框架、无构建流程、无外部 API。

## 功能

- 响应式中文首页，适配桌面端和移动端
- 现代渐变英雄区与“关于项目”内容区
- “云端开发”“无需本地安装”“一键部署”三张功能卡片
- 可交互的“开始体验”按钮和友好提示消息
- 键盘焦点样式、动态内容播报和减少动态效果偏好支持

## 本地查看

直接使用浏览器打开 `index.html`，或在项目目录启动任意静态文件服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 文件结构

```text
.
├── index.html  # 页面结构和内容
├── style.css   # 响应式布局与视觉样式
├── script.js   # 按钮交互与动态年份
└── README.md   # 项目说明
```
